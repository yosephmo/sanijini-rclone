rclone · 사니지니 백업

이 페이지는 Google OAuth 클라이언트 「rclone」의 안내입니다. 사니지니(개인사업자)가 자기 파일을 자기 Google 드라이브에 백업할 때 오픈소스 도구 rclone으로 씁니다.

사니지니 한 사람만 쓰는 도구이고, 다른 사람의 데이터에는 접근하지 않습니다. 따로 서버가 없고, 드라이브 접근 토큰은 사니지니의 컴퓨터에만 있습니다.

rclone · Sanijini backup

This page describes the Google OAuth client “rclone”. Sanijini, a sole proprietorship, uses it with the open-source tool rclone to back up its own files to its own Google Drive.

It is used only by its owner and does not access anyone else’s data. There is no server; the Drive access token is stored only on the owner’s computer.
